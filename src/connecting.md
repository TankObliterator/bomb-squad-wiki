# How to connect

We support multiple connection methods for both editions of the game. Please use the topmost method that suits you the best.

## Java
### Standard
> **`seafmc.org`**

### Raknetify
> **`raknet;seafmc.org`**

## Bedrock
### Universal
> Add **`SEAF MC`** as a Minecraft Friend.

### Classic
> IP: **`seafmc.org`** Port: **`19132`**
